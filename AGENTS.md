# AI Assistant Operational Rules & Teaching Contract

This repository follows a strict engineering teaching contract:
1. Explain the goal, design, and tradeoffs before writing code.
2. Build in small, verifiable steps. Never dump massive multi-file scripts at once.
3. Every terminal command must be explained.
4. Verify every change with real test output before moving to the next task.
5. No cloud resources may be provisioned without explicit cost review and learner approval.
6. Secrets, credentials, private keys, and state files must never be committed.
